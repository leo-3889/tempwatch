**TempWatch — hardware temperature monitor for Linux (GTK3)**

A live sensor dashboard for /sys/class/hwmon with readable sensor names, session min/max, firmware limits and a per-sensor temperature graph. Python, MIT licensed, no dependencies beyond python3-gi.

**🌡 Sensors shown**
- CPU package and per-CCD temps (k10temp, coretemp)
- Individual DDR5 DIMM temps (spd5118)
- Motherboard sensors incl. the TSENSOR1 header on ASUS ProArt B850-Creator (NCT6799D Super I/O; the board's "EC" exposes nothing on Linux)
- GPU core / hotspot / memory (amdgpu, nvidia) and NVMe drives

**📌 Desktop integration (GNOME)**
- Tray icon with live value of the pinned sensor
- Right-click a sensor → show its value permanently in the top bar (Vitals extension)
- Minimize hides to tray, tray restores; single instance

**🛠 Install (Ubuntu 22.04+)**
```
git clone https://github.com/leo-3889/tempwatch && cd tempwatch && ./install.sh
```
Debian package: tempwatch_1.1.14_all.deb from
https://github.com/leo-3889/tempwatch/releases
(SHA256SUMS included; install smoke-tested in CI)

A terminal version (`tempwatch`) ships in the same package for headless use.

Platform support is a single registry table in the source; the README documents adding a driver.

**Tested on:** Ryzen 9 9950X, ASUS ProArt B850-Creator WIFI NEO, AMD GPU, DDR5-6000, GNOME 50 / Wayland.
